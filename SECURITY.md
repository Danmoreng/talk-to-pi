# Security policy

Please do not report suspected security vulnerabilities in downloaded assets or native process handling in public issues. Use **Security → Report a vulnerability** in the GitHub repository (private vulnerability reporting must remain enabled) and include:

- a description of the issue;
- affected version or commit;
- reproduction steps;
- relevant logs with transcript and audio content removed.

Talk-to-Pi treats runtime and model downloads as supply-chain-sensitive. Release assets must be fetched from immutable URLs and verified by exact size and SHA-256 before execution.
